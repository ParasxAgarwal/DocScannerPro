# UI Design

Doc Scanner uses a document-first Android layout built around native touch patterns and restrained visual hierarchy.

The library emphasizes readable lists, compact actions, contextual menus, simple category tabs, and a persistent scan action. Documents are the primary content and specialized capture modes live under Tools.

The scanner uses a dark camera workspace with minimal controls, a clear capture hierarchy, contextual mode selection, and a single primary shutter action.

The application uses a neutral surface system with a restrained blue action color. Screens do not depend on gradients, decorative cards, AI-style visual effects, or web-style dashboard layouts.

The bottom navigation contains Documents, Tools, Favorites, and Settings. Notes remain contextual to documents rather than being a separate top-level destination.
